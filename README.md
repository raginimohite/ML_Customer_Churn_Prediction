Customer Churn Prediction

Project Overview

This project predicts whether a customer is likely to leave a company using Machine Learning. It uses a Streamlit dashboard to display customer information and prediction results.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib
- Machine Learning

Features

- Displays total customers and churned customers.
- Accepts customer details as input.
- Predicts customer churn.
- Provides customer retention suggestions.

How to Run

1. Install the required libraries:
   "pip install -r requirements.txt"
2. Run the application:
   "python -m streamlit run Customer_Churn_ML_DashBoard.py"

Project Files

- "Customer_Churn_ML_DashBoard.py" – Main Streamlit application
- "customer_churn.csv" – Customer dataset
- "Marvellous_ML_Customer_Churn.pkl" – Trained ML model
- "requirements.txt" – Required Python libraries
